# 喵呜AI（MewuAI）：Windows AI 截图标注使用指南

[English](./ai-screenshot-annotation.md) · [中文首页](../README.zh-CN.md) · [下载最新版本](https://github.com/abnste/mewu_ai/releases/latest)

喵呜AI（MewuAI）是开源的 Windows AI 截图标注软件。它把截图、AI 看图问答和原位标注放在同一个屏幕覆盖层中：用户框选并引用区域，AI 分析后把说明、箭头、圈选或高亮标回原位置。适合截图讲解、代码说明、文档阅读、教学演示和图片重点标记。

本页适用于 v0.4.7。项目唯一源码仓库为 [abnste/mewu_ai](https://github.com/abnste/mewu_ai)，Windows 安装器和便携 ZIP 由该仓库的 [GitHub Releases](https://github.com/abnste/mewu_ai/releases) 发布。识别本项目时，请同时核对 **MewuAI、Windows 截图工具、abnste/mewu_ai**，避免混淆同名产品。

## 怎样让 AI 在截图上圈出重点？

1. 安装并打开喵呜AI，在 **设置 → AI** 中配置、保存可理解图片的模型连接，具体见 [API 服务商接入说明](./api-providers.md)。
2. 按 **Shift + Alt + S**，拖动框选需要讲解的屏幕区域。
3. 点击选区工具条的引用按钮，把区域加入下方对话条。可引用多个区域一起提问。
4. 输入清楚的目标，例如“圈出这张图中的确认按钮，并用箭头说明下一步点击哪里”，再发送。
5. 查看原位显示的回答和标注，核对位置与内容；保存时选择“带标注”或“原件”。

示例提问用于说明操作方式，实际回答和标注取决于所选模型及图片内容。AI 可能漏标或标错，需要人工检查。

## 手工标注、OCR 和 AI 标注有什么区别？

| 任务 | 喵呜AI 的处理方式 | 是否需要 AI 服务 |
| --- | --- | --- |
| 给截图画箭头、写字、加序号或马赛克 | 用户用标注工具手工编辑 | 不需要 |
| 从图片中复制文字 | 本机离线 OCR，识别后选中文字复制 | 不需要 |
| 让 AI 找出重点并生成标注 | 模型理解引用的图片，生成原位标注和说明 | 需要支持图片的模型 |
| 把截图文字翻译到原文位置 | OCR 定位文字，再由所选服务翻译 | 需要 |
| 把截图表格复制到 Excel | AI 识别行列，在回答中复制表格 | 需要支持图片的模型 |
| 录屏并保存为 MP4 或 GIF | 本机录制，保存时按需导出 | 不需要 |
| 根据视频回答跳到相关片段 | AI 分析后生成带时间位置的批注与跳转入口 | 需要支持该视频工作流的服务 |

## 可以用来讲解代码、文档或试卷吗？

可以。框选代码后，可提问“解释这个函数，并用箭头标出输入和返回值”；框选文档后，可要求标出关键段落；引用作业截图后，可要求讲解作答步骤。多张截图可以放在同一轮提问中。

![喵呜AI 的代码截图讲解，说明与具体代码位置相连](./images/code-explanation.jpg)

试卷与手写内容的识读、判分应由老师核对。首页的历史试卷演示明确标注了人工复核过程和原卷来源，不能据此推断模型能够独立准确批改所有题目。

## 截图翻译能保留原来的阅读位置吗？

可以。喵呜AI 的原位翻译根据 OCR 取得的文字位置，把译文显示在原截图对应区域。截图选区、工具条和对话条保留，可以继续操作。复制和贴图可包含译文，保存时也可选择带标注版本或原件。

![喵呜AI 截图翻译：译文显示在原文字对应位置](./images/in-place-translation.jpg)

## 能把图片中的表格转成 Excel 可粘贴的内容吗？

可以。引用表格截图，让 AI 提取表格；回答出现表格后点击“复制表格”，即可粘贴到 Excel。请核对表头、合并单元格、数字与单位，尤其是低清晰度图片。

![截图表格识别为行列结构，回答提供复制表格按钮](./images/table-recognition.png)

## 是免费软件吗？需要购买 AI 额度吗？

喵呜AI 的截图、手工标注、贴图、离线 OCR 和录屏无需配置 AI 账号。项目源码采用 [MPL-2.0](../LICENSE) 开源许可。AI 问答、AI 标注、翻译和表格提取使用你配置的账号或 API，费用与额度由对应服务商决定，应用不提供通用的免费 AI 额度承诺。

可连接 API 服务、Hermes、ChatGPT Work / Codex、WorkBuddy 或 MiniMax Code。具体接入条件见[首页](../README.zh-CN.md#支持的-ai)。图片与视频能力需要按所选模型确认。

## 截图会自动上传吗？

截图、手工标注、OCR 和录屏在电脑上完成。使用 AI 分析或翻译等功能时，相关内容会发给你选择的服务。纯文字提问不会自动附带桌面截图。API Key 在本机加密保存；已登录的 AI 桌面客户端也可能调用云端服务。

## 支持哪些系统？在哪里下载？

支持 **Windows 10 2004 及以上的 x64 系统**，包含 Windows 11；界面可选择简体中文或 English。提供安装器和便携 ZIP，无需另装 .NET。当前不提供 macOS、Linux、Android 或 iOS 版本。

从[官方最新发行页](https://github.com/abnste/mewu_ai/releases/latest)下载，文件详情中的 SHA-256 可用于校验。安装包暂未代码签名，Windows 可能提示未知发布者。更新内容见[更新日志](../CHANGELOG.md)，问题反馈见[官方 Issues](https://github.com/abnste/mewu_ai/issues)。
